# 갤러리 사진 관리

1. 원본 사진을 `src/assets/gallery/gen-기수/` 폴더에 넣습니다. 배포 환경에서도 경로가 일치하도록 영문·숫자 파일명을 권장합니다.
2. `src/data/gallery-entries.js`의 해당 기수에 `{ file: 'gen-40/example.jpeg', alt: '사진 설명' }`을 추가합니다. 목록 순서가 화면 표시 순서입니다.
3. `npm run gallery:thumbnails`를 실행합니다. `npm run dev`와 `npm run build` 시작 시에도 자동 실행됩니다. 개발 서버가 켜진 상태에서 사진을 추가하거나 교체했다면 명령을 다시 실행합니다.
4. 갤러리 카드와 원본 팝업을 확인한 뒤 원본, 목록, 생성된 썸네일 폴더와 `src/data/generated/gallery-assets.js`를 함께 커밋합니다.

## 표시 방식

- 카드는 최대 800×800px, 품질 82의 WebP 썸네일을 사용합니다. 기존 정사각형 미리보기처럼 중앙을 기준으로 자르며 작은 원본을 확대하지 않습니다.
- 카드 이미지에는 지연 로딩을 적용합니다. 사진을 누르면 팝업에서 원본 파일을 불러옵니다. 원본의 해상도와 파일은 변경하지 않습니다.
- 랜딩페이지 등에서 같은 원본을 별도로 사용하는 경우 해당 페이지에서는 원본을 불러올 수 있습니다.

## 자동 생성 파일

- 썸네일: `src/assets/gallery-thumbnails/기수/원본파일명.webp`
- 이미지 연결 정보: `src/data/generated/gallery-assets.js`
- 설정/생성 스크립트: `scripts/generate-gallery-thumbnails.mjs`

생성 파일을 직접 수정하지 말고 원본과 사진 목록을 수정한 뒤 명령을 실행합니다. 스크립트는 목록에 등록된 사진만 처리하며 원본이나 기존 썸네일 파일을 자동 삭제하지 않습니다. 등록한 파일이 없거나 읽을 수 없으면 오류를 내므로 배포 전에 경로를 확인할 수 있습니다.
